## 🚀 Overview

We leave digital breadcrumbs everywhere—transactions, subscriptions, rides, and media logs. **Life Receipts** aggregates these disparate raw datasheets into a cohesive, immersive consumer experience. Instead of boring spreadsheets, your data tells your story.

## ✨ Key Features

- 📖 **Story Chapters:** Temporal storytelling that groups historical records into meaningful life chapters.
- 🌌 **Constellation Map:** A visual network mapping cross-modal connections between digital footprints.
- 🔍 **Raw Datasheet Vault:** Searchable, filterable data grid with real-time analytics and category totals.
- 🤖 **AI Behavioral Synthesizer:** Dynamic, local-only synthesis of the loaded records.
- 📋 **Share Card Export:** Instantly copy a summary card of the digital archive.
- 🎞️ **Memory Replay:** Cinematic replay of the discovered receipt story.
- 🖱️ **Interactive TRACE Cursor:** Cursor-reactive depth and ambient visual feedback on supported devices.

## 🛠️ Tech Stack

- **Frontend:** React, Vite
- **Styling:** Tailwind CSS, Glassmorphism UI
- **Motion:** Framer Motion and Lenis
- **Icons:** Lucide React
- **Hosting & Deployment:** Vercel
- **Backend:** None — 100% frontend-only
